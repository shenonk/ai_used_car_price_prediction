# AI-Powered Used Car Price Prediction System

## Final Year Project – BSc (Hons) Computer Science (PUSL3190)

This project develops an AI-powered web application that predicts used car prices and estimates vehicle loan costs tailored to the Sri Lankan market.

## Current Progress
- Repository initialized
- Project folder structure created
- PID completed
- UI design and frontend development in progress

## Planned Features
- Used car price prediction using machine learning
- Vehicle loan cost estimation (EMI, interest, tenure)
- Analytics dashboard (price trends, comparisons)
- In-app notifications
- Downloadable PDF reports

## Technologies (Planned)
- Frontend: React, Tailwind CSS
- Backend: FastAPI
- ML: Random Forest, XGBoost
- Database: PostgreSQL
